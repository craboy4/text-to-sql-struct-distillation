# BIRD Mini-Dev 作者 EX 评测

本项目的主结果使用 BIRD Mini-Dev 作者仓库中的 `evaluation/evaluation_ex.py`，副本位于 `evaluation/author_minidev/`。

## 定义

对每题，分别执行预测 SQL 和 gold SQL。若两个结果的**集合**相等，记为正确；结果行的顺序和重复次数不参与比较。总 EX 为正确题数除以 500。

这与本项目早期 `training/evaluate_minidev.py` 的多重集比较不同。多重集比较会保留重复行数量，标准更严格。因此报告分数时必须标注评测器，不能直接混用两个口径。

## 输入适配

本地和远端推理输出使用 JSONL，每行含 `question_id` 和 `sql`；作者脚本要求按照 Mini-Dev 原始顺序的 JSON 映射，并在 SQL 后附带数据库标识。`training/prepare_author_ex_predictions.py` 完成该转换，不改写 SQL。

当前 Mini-Dev 推理数据中有 498 个 question_id，缺少 `119` 和 `120`。适配器会为缺失题写入空 SQL，因此作者 EX 始终按 500 题计算，缺失项明确计错。
