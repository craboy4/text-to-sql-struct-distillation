## 发布规则

1. 代码、配置、文档和小型评测日志提交至 Git。
2. SFT 数据发布到指定数据仓库，附带 schema、样本数、许可证、SHA-256 和构造命令。
3. LoRA adapter 发布到指定模型仓库，附带基座模型、训练配置、评测版本、结果和 SHA-256。
4. 不上传 API key、教师原始响应中可能包含的敏感信息或未审查的数据库内容。
